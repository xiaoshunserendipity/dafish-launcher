大肥鱼启动器 v3.6.0 使用说明（免安装）
=======================================

【这是什么】
一个本地程序启动管理器：把 AstrBot、SnowLuma、GSVI 之类的程序登记成卡片，
用开关 / 总开关一键启停，支持托盘、顺序启动、全屏与进程避让、崩溃自动重启。


【三步用起来】
1. 把整个文件夹放在任意有写权限的位置（例如 D:\Tools\我的AI工具\），
   双击「大肥鱼启动器.exe」。
2. 点卡片上的「设置」选择目标程序；或点底部「＋ 添加启动项」。
3. 拨卡片开关启动，拨右上角「全部启动」按顺序启动全部。


【自定义图标】
卡片左侧图标默认是 emoji。想换成图片：
    卡片「设置」→「图标图片」→「选择图片…」
支持 png / jpg / webp / ico / svg，会自动裁成圆角正方形。
设了图片就优先显示图片，文件丢了才回落到 emoji。
图片放在启动器目录内时路径会存成 ${APP}\...，换电脑不丢。


【全屏避让】

    设置 →「全屏时暂停参与避让的程序」      总开关
    卡片「设置」→「全屏避让 / 进程避让」    决定这一条参不参与

    设置 →「额外判定为全屏的进程」          内置名单之外，再把这些算作全屏
    设置 →「不计入全屏的进程」              优先级最高，这些不算全屏
    格式：逗号分隔，可省略 .exe，例如 chrome.exe, myplayer

【开机动画】
启动时播一段开屏动画，可以自己换：把 boot.webp 或 boot.gif 放到启动器同目录即可，
不用重新打包。删掉外部文件就回落到内置的那份。

    内置动画来源：https://github.com/Something11235/dsh-video-skin （MIT）
    想换成自己的，按下面的方法替换即可。

    设置 → 启动时显示开机动画     可以整个关掉
    开屏时点任意处                 可以跳过

支持动态 WebP（推荐，体积最小）、GIF、PNG 序列。
不支持 MP4 —— 需要额外的视频组件，用 ffmpeg 转成 webp 即可：

    ffmpeg -i boot.mp4 -t 6 -vf "setpts=PTS/3,fps=24,scale=900:-1" ^
           -c:v libwebp -loop 0 -q:v 50 -an boot.webp

建议时长 0.8–2.0 秒；超过 3 秒会明显拖慢启动。
注意：双击后前约 1 秒是单文件解压，那段时间没有界面，动画只能在之后出现。


【支持哪些目标】
卡片可以指向任意磁盘上的程序或脚本，数量没有上限：

    .exe / .com    直接启动，完整支持跟踪与停止
    .bat / .cmd    通过 cmd.exe 运行，窗口形态可选，完整支持
    .lnk 快捷方式  交给系统 Shell，只能启动一次，无法跟踪状态

.py / .ps1 / .vbs 不能直接选（Windows 不当作可执行文件）。
想管这类脚本，包一层 .bat 即可，例如：
    @echo off
    python "%~dp0myscript.py"


【重要：怎么让它真正便携】
把要启动的程序放在启动器所在文件夹内（或子文件夹），例如：

    我的AI工具\
    ├─ 大肥鱼启动器.exe
    ├─ AstrBot\
    │  └─ astrbot-desktop-tauri.exe
    └─ SnowLuma\
       └─ launcher.bat

这样保存时路径会自动记成 ${APP}\AstrBot\astrbot-desktop-tauri.exe，
整个文件夹搬到任何路径、任何电脑都不用重新设置。

卡片上出现「便携路径」小标记，就说明这条记录是可搬迁的。


【批处理窗口怎么显示】
每个卡片可以单独选「窗口形态」—— 在卡片上右键 →「窗口形态」，或进「设置」里改：

    正常窗口        弹出普通控制台窗口，输出显示在窗口里
    最小化到任务栏  窗口最小化，点任务栏图标可恢复查看
    后台运行        完全不弹窗，输出进「日志」面板（pause 会被自动跳过）

服务类批处理（SnowLuma、GSVI 这类）建议用「最小化到任务栏」或「后台运行」，
免得每次启动都弹一个窗口出来。卡片上会显示当前是哪种形态。


【启动后自动打开网页】
有些程序会提供一个网页界面（比如 SnowLuma 的 WebUI 在 5099 端口）。
卡片「设置」里勾选「启动后自动用浏览器打开服务地址」，然后二选一：

    就绪端口 = 5099          → 端口一通就打开 http://127.0.0.1:5099/
    打开的地址 = 127.0.0.1:5099/ui  → 打开你填的这个（优先级低于就绪端口）

两个都空着时，启动器会尝试从控制台输出里找地址 —— 但只有「后台运行」
形态才有输出可读，正常窗口 / 最小化形态下启动器看不到输出。

出于安全考虑，只打开本机与局域网地址（127.x / localhost / 192.168.x / 10.x）。
输出里的外部网址会被拒绝并记进日志。


【常用操作】
- 单个启停：拨卡片右上角的圆开关
- 顺序启动：拨「全部启动」，按卡片顺序依次启动
- 拖拽添加：把 exe / bat / cmd / lnk 文件直接拖进窗口就自动建卡片
- 分享配置：卡片右键 →「复制配置（JSON）」，对方右键 →「从剪贴板添加条目」
- 日志：底部「日志」展开，可按条目过滤、按关键字搜索
- 托盘：图标右下角有绿点表示有服务在跑，悬停看运行数
- 资源占用：运行中的卡片右下角显示 CPU 和内存，每 3 秒刷新
- 全局热键：设置里开启后，Ctrl+Alt+S 全部启动 / Ctrl+Alt+X 全部停止
  （热键被别的程序占用时会自动换一组，开启时会提示实际组合）
  也可以自定义：设置里那两个输入框，点进去直接按组合键。
  启动 / 停止各自独立 —— 填了用你的，留空用候选组合，可以只改其中一个。
  必须带 Ctrl / Alt / Shift / Win 之一。
- 端口冲突：会显示占用进程名和 PID，可直接「结束它并启动」
- 深色主题：设置里可切换，卡片会换成深灰底 + 浅色字
- 服务连续异常退出 5 次后会弹托盘气泡提醒，卡片变红


【它不会做什么】
- 打开时不会主动启动任何程序（所有开关默认关闭）。
- 不会写 AppData（配置就在本文件夹；只有勾了开机自启才写 HKCU Run）。
- 不会改动你填的程序本身。


【常见功能】
- 总开关：按卡片顺序依次启动，等上一个真正就绪再启动下一个。
- 每个条目可设置：窗口模式、延迟启动、自动重启、端口预检、就绪端口、
  分组、是否参与全屏避让、是否参与目标进程避让、是否允许启动接管、输出方式。
- 触发器：监控某些 exe / 目录，命中时自动挂起勾选了「进程避让」的服务。
- 启动接管：服务已经在跑时会自动扫描并接管，卡片显示「运行中 · 已接管」。
- 托盘：点 X 只是收进托盘；右键可单独启停、扫描已运行、全部停止并退出。
- 日志：底部「日志」面板，可按条目过滤；右侧可导出诊断包。


【配置与日志在哪】
默认就在 exe 同目录：
    config.json          配置
    detect_rules.json    自动探测规则（可自己编辑）
    logs\launcher.log    运行日志
    logs\crash.log       崩溃日志

如果 exe 放在不可写目录（如 C:\Program Files），配置会自动改存到
    %LOCALAPPDATA%\大肥鱼启动器
启动时日志里会说明，「设置 → 关于」也能看到当前用的是哪种模式。
想保持便携，就把 exe 放在有写权限的普通文件夹里。


【第一次运行被拦】
这是 PyInstaller 单文件程序的常见误报：
- SmartScreen：点「更多信息」→「仍要运行」
- 杀毒软件：把 exe 加入信任 / 白名单


【系统要求】
Windows 10 / 11 64 位。不需要安装 Python 或任何依赖，单文件直接运行。
