# 大肥鱼启动器 用户指南

**适用版本：** v3.4.2
**适用系统：** Windows 10 / 11 64 位
**更新日期：** 2026-10-26

---

## 1. 这是什么

一个 Windows 本地程序启动管理器。把需要按顺序启动的程序（AstrBot 桌面版、SnowLuma、GSVI 语音适配器等）登记成卡片，用开关一键启停。

核心特点：

- **免安装、免环境**：单文件 exe，目标电脑不需要装 Python、PySide6 或 VC++ 运行库
- **绿色便携**：配置和日志都在 exe 同目录，拷走文件夹就能用
- **配置可搬迁**：程序目录内的路径自动记成相对形式，换电脑/换盘符后依然有效
- **默认不自动启动**：打开软件不会主动拉起任何程序
- **单实例**：重复双击不会多开
- **状态感知**：全屏、目标进程、已运行服务都能识别，自动暂停或接管

### v3.4 修复的问题

- 删光所有卡片后重启，不会再自动补回默认的三个条目
- 单实例锁在部分情况下失效，导致可以同时开两个启动器
- 日志超过 2MB 轮转后 `launcher.log` 停止更新、日志全部写进备份文件
- 启动参数里带空格的路径会被引号污染，传给目标程序时出错
- 「全部停止并退出」时，接管的进程有时杀不干净
- 按 PID 结束进程时增加身份校验，避免系统复用 PID 后误杀无关程序
- **批处理（.bat/.cmd）的输出不再被日志面板吞掉** —— 之前会弹出一个空白控制台窗口，看起来像没运行
- **托盘「全部停止并退出」不再卡死** —— 有程序在运行且不输出内容时，退出会永久卡住；现在正常结束并退出
- **窗口形态三选一**：正常窗口 / 最小化到任务栏 / 后台运行（不弹窗），每个卡片独立设置，卡片右键即可切换
- **后台运行模式下 `pause` 不再卡死** —— 启动器会给它空输入流，`pause` 自动跳过
- **自动打开服务地址**：每个卡片可单独开启，支持「就绪端口 → 手填地址 → 输出抓取」三级兜底，只放行本机/局域网地址

## 2. 三步开始用

**第一步** 把「大肥鱼启动器.exe」放到任意文件夹，例如 `D:\Tools\启动器\`，双击运行。

**第二步** 首次运行会在同目录生成：

| 文件 | 作用 |
|---|---|
| `config.json` | 配置（启动项、触发器、全局设置） |
| `detect_rules.json` | 自动探测规则，可自己编辑 |
| `logs\` | 运行日志与崩溃日志 |

**第三步** 点卡片上的「设置」选择目标程序；或点底部「＋ 添加启动项」。

> 路径可以先留空。未设置路径时点开关，会提示「还没有设置路径」。

### 支持哪些目标

卡片可以指向任意磁盘上的可执行文件或脚本，**数量没有上限**：

| 类型 | 怎么启动 | 能否跟踪 / 停止 |
|---|---|---|
| `.exe` / `.com` | 直接启动 | ✅ 完整支持 |
| `.bat` / `.cmd` | 通过 `cmd.exe /c` 运行，窗口形态可选 | ✅ 完整支持 |
| `.lnk` 快捷方式 | 交给系统 Shell | ❌ 只能启动一次，状态无法跟踪 |

`.py` / `.ps1` / `.vbs` / `.jar` 这类不能直接选 —— Windows 不把它们当作可执行文件，直接启动会报「不是有效的 Win32 应用程序」。

**想管这类脚本，包一层 `.bat` 就行**，例如：

```bat
@echo off
python "%~dp0myscript.py"
```

然后把这个 `.bat` 加进卡片，窗口形态、自动重启、避让这些能力就都能用了。

每个条目的能力完全独立：参数、工作目录、窗口形态、延迟启动、自动重启、端口预检、就绪端口、自动打开地址、分组、全屏避让、进程避让、启动接管、自定义图标，逐个配。

### 自定义图标

卡片左侧的图标默认是一个 emoji（可以自己改）。想换成图片：

**卡片「设置」→「图标图片」→「选择图片…」**

- 支持 `png` / `jpg` / `webp` / `ico` / `svg`
- 自动裁成圆角正方形，超出部分居中裁切
- **图片优先于 emoji**：设了图片就显示图片；没设、或文件丢失时回落到 emoji 字符
- 图片放在启动器目录内时，路径会自动存成 `${APP}\...`，换电脑仍然有效
- 点「清除」去掉图片，回到 emoji

> 建议把图标图片放进启动器目录（比如 `icons\` 子文件夹），这样整个文件夹搬走图标也不会丢。

## 3. 便携模式的三种情况

启动器会先尝试把配置存在 exe 同级目录。如果那个目录不可写，会自动换个地方存 —— 不需要你手动设置。

| 情况 | 配置存哪 | 怎么判断 |
|---|---|---|
| 放在普通文件夹 / U 盘 / 桌面 | exe 同级目录 | 便携模式，拷走文件夹即可 |
| 放在 `C:\Program Files`、受控目录、只读介质 | `%LOCALAPPDATA%\大肥鱼启动器` | 启动时日志会写一行「程序所在目录不可写，配置与日志已重定向到…」 |
| 设置了环境变量 `LAUNCHER_CONFIG` | 该变量指定的路径 | 用于测试或特殊部署 |

查看当前用的是哪种：**设置 → 关于**，会显示「运行模式」和实际的配置路径。

> 注意：一旦降级到用户目录，配置就不再跟着 exe 走了。想保持便携，请把 exe 放在有写权限的普通文件夹里。

## 4. 让配置跟着文件夹走（`${APP}`）

这是本版最重要的改动。

### 规则

凡是位于**启动器所在目录内**的路径，保存时会自动写成 `${APP}\...` 的形式：

```json
{
  "name": "AstrBot 桌面版",
  "path": "${APP}\\AstrBot\\astrbot-desktop-tauri.exe",
  "cwd":  "${APP}\\AstrBot"
}
```

`${APP}` 在运行时展开成 exe 所在目录。所以只要文件夹内部的相对结构不变，**整个文件夹搬到任何路径、任何电脑，路径都还有效**。

### 界面上怎么看

- 卡片路径栏显示的是**展开后的真实绝对路径**（方便你确认指向哪里）
- 卡片上会多一个「便携路径」小标记，表示这条记录是可搬迁的
- 在「设置启动项」对话框里，如果填的路径落在启动器目录内，下方会出现绿色提示：`✓ 位于启动器目录内，保存时会转成便携路径`

### 推荐目录布局

```
D:\Tools\我的AI工具\          ← 整个文件夹打包发给别人
├─ 大肥鱼启动器.exe
├─ config.json
├─ detect_rules.json
├─ AstrBot\
│  └─ astrbot-desktop-tauri.exe
├─ SnowLuma-v2.1.1-win-x64\
│  └─ launcher.bat
└─ 语音库模型\
   └─ GPT-SoVITS-v5\...\启动GSVI适配器.bat
```

启动器放在这个结构的**根目录**，所有目标程序都在它下面，全部路径都会自动变成 `${APP}\...`。

### 程序目录外的路径怎么办

不在启动器目录内的路径（例如 `E:\Games\xxx.exe`）保持绝对路径不变。这类条目换电脑后需要重新设置 —— 界面不会骗你，卡片会变灰并提示「路径不可用」。

## 5. 自动探测路径

点底部「自动探测路径」，启动器会按 `detect_rules.json` 里的规则，给**还没有设置路径**的条目填上目标文件。已经设置过的条目不会被覆盖。

### 规则文件结构

```json
{
  "version": 1,
  "search_roots": ["${APP}", "${APP}/.."],
  "rules": [
    {
      "keywords": ["astrbot"],
      "patterns": ["AstrBot/astrbot-desktop-tauri.exe", "astrbot-desktop-tauri.exe"]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `search_roots` | 搜索起点列表。`${APP}` 是启动器目录，`${APP}/..` 是它的上一级 |
| `rules[].keywords` | 条目名称里包含任一关键词即命中（不区分大小写） |
| `rules[].patterns` | 相对路径会拼到每个 `search_roots` 后面；含 `${APP}` 或以盘符开头则直接使用 |
| 通配符 | `patterns` 支持 `*` 和 `?`，取第一个存在的文件 |

### 换成自己的程序

比如要加一个叫「我的机器人」的程序，放在启动器同级的 `MyBot\bot.exe`：

```json
{
  "keywords": ["我的机器人", "mybot"],
  "patterns": ["MyBot/bot.exe"]
}
```

保存后重新点「自动探测路径」即可。规则文件损坏或格式不对时，启动器会自动回退到内置默认规则，不会崩溃。

## 6. 界面速查

| 区域 | 内容 |
|---|---|
| 顶部 | 标题、日期、状态徽章（🟢 监控中 / 🟡 触发避让）、「全部启动」总开关 |
| 卡片 | 图标、名称、路径、运行状态、独立开关、挂起标签；可拖拽排序 |
| 底部按钮 | 添加启动项、编辑模式、自动探测路径、设置、分组、触发器、日志、全部停止 |

### 常用操作

- **单个启停**：拨卡片右上角的圆开关
- **顺序启动**：拨「全部启动」，按卡片顺序依次启动，等上一个真正就绪再启动下一个
- **排序**：直接拖动卡片
- **拖拽添加**：把 `.exe` / `.bat` / `.cmd` / `.lnk` 文件直接拖进窗口，自动建卡片（名字取文件名，路径和目录自动填好），一次可以拖多个
- **卡片右键**：启动/停止、打开所在目录、复制路径、**复制配置（JSON）**、**从剪贴板添加条目**、窗口形态、设置、删除
- **日志**：点底部「日志」展开，可按条目过滤、**关键字搜索**，可导出诊断包
- **托盘**：点 X 只是收进托盘。托盘图标右下角有**绿点**表示有服务在跑，鼠标悬停能看到「大肥鱼启动器 · N 个运行中」
- **资源占用**：运行中的卡片右下角会显示 CPU 和内存（含子进程），每 3 秒刷新
- **全局热键**（需在设置里开启）：默认 `Ctrl+Alt+S` 全部启动 / `Ctrl+Alt+X` 全部停止。热键是系统独占的，被占用时会自动换一组候选组合（S/F10 → Ctrl+Shift+S/Q → F9/F10），开启时会提示实际生效的组合
  - **可以自定义**：设置 →「启用全局热键」下面两个输入框，点进去直接按组合键即可
  - **启动 / 停止各自独立**：填了就用你填的，留空就用候选组合 —— 可以只自定义其中一个
  - 自定义时**必须带 Ctrl / Alt / Shift / Win 之一**，纯字母键会被拒绝（避免抢走正常输入）
- **端口冲突**：启动前若发现端口被占，会显示**占用进程名和 PID**，可以直接点「结束它并启动」

### 深色主题

设置里可以选「跟随系统 / 浅色 / 深色」。深色下卡片会换成深灰底 + 浅色文字，不是简单地把界面压暗。

### 分享单个条目

卡片右键 →「复制配置（JSON）」，剪贴板里会得到一条完整配置（不含 id）。对方在任意卡片上右键 →「从剪贴板添加条目」即可导入，也支持一次粘贴一个数组批量导入。

## 7. 窗口形态：正常 / 最小化 / 后台

每个启动项可以单独选一种窗口形态。位置：**「设置启动项 → 窗口形态」**，也可以直接在卡片上**右键 → 窗口形态**切换。

| 形态 | 效果 | 输出在哪 | 适合 |
|---|---|---|---|
| **正常窗口** | 弹出普通控制台窗口 | 窗口里 | 需要边跑边看输出 |
| **最小化到任务栏** | 窗口最小化，点任务栏图标可恢复 | 窗口里 | 不想被窗口挡住，但想随时能看 |
| **后台运行（不弹窗）** | 完全不创建窗口 | 「日志」面板 | 服务类程序，只在需要时翻日志 |

卡片上会显示「最小化」或「后台运行」小标记，一眼能看出当前是哪种。

### 三种形态的差别

- **正常 / 最小化**：子进程使用真实控制台，输出直接显示在窗口里。批处理里的 `pause` 会正常等待按键。
- **后台运行**：不创建任何窗口，输出重定向到日志面板。为了不让批处理卡住，启动器会给它一个空的输入流 —— 所以 **`pause` 会被自动跳过**，不会挂在结尾。

### 为什么没有"最小化到系统托盘"

`.bat` 本身没有窗口属性，必须由 `cmd.exe` 承载。启动器只能控制 `cmd.exe` 创建控制台时的参数，所以只有上面三种形态。托盘图标需要程序自己调用系统接口创建，`cmd.exe` 不会做。

> 如果批处理内部用 `start "" xxx.exe` 拉起别的程序，那个程序的窗口由它自己决定，启动器管不到。

## 8. 自动打开服务地址

有些程序启动后会在输出里打印一个网页地址（比如 SnowLuma 的 WebUI）。可以让启动器在启动成功后自动用默认浏览器打开它。

### 怎么开

卡片「设置」→ 勾选「启动后自动用浏览器打开服务地址」，然后二选一：

| 填什么 | 打开的地址 |
|---|---|
| **就绪端口** = `5099` | `http://127.0.0.1:5099/` |
| **打开的地址** = `127.0.0.1:7000/ui` | `http://127.0.0.1:7000/ui`（自动补 `http://`） |

两个都填时**以就绪端口为准**。都不填时，启动器会尝试从控制台输出里找地址 —— 但只有「后台运行」形态才有输出可读，正常/最小化形态下输出在控制台里，启动器看不到。

### 优先级

1. **就绪端口** → `http://127.0.0.1:端口/`
2. **手填地址**
3. **从输出里抓**（仅「后台运行」形态有效）

### 安全限制

**只打开本机与局域网地址**：`localhost`、`127.x`、`10.x`、`172.16–31.x`、`192.168.x`、`::1`。

输出里的外部网址（例如 `https://example.com`）会被拒绝，并在日志里留一条记录。因为批处理输出不可信 —— 万一脚本被人改过，打印一个恶意网址，启动器不能替你打开。

### 其他细节

- 进程进入「运行中」后**延迟 1.5 秒**再打开，给服务一点启动时间
- 每轮启动只打开**一次**；程序崩溃自动重启后不会重复弹浏览器
- 卡片右键有「打开网页」，可以随时手动打开（配置了就绪端口或地址才会出现）

## 9. 日志与排障

| 文件 | 内容 |
|---|---|
| `logs\launcher.log` | 运行日志：启动/停止、避让、接管、路径失效等 |
| `logs\crash.log` | 崩溃日志：未捕获异常、线程异常、硬崩溃栈、Qt 警告 |

「导出诊断包」会把这些一起打包成 zip：`config.json` + 全部日志（含 `crash.log`）+ 系统信息（版本、运行模式、数据目录、当前状态）。

### 日志面板

- 左上角下拉框可以**只看某个条目**的日志
- 旁边的搜索框可以**按关键字过滤**（内容或条目名都能搜，不区分大小写）
- 「清空」只清空面板显示，磁盘上的日志文件不受影响

### 服务挂了会提醒你

如果某个条目开了「自动重启」，但连续异常退出超过 5 次，启动器会：

1. **弹出托盘气泡通知**（不会一闪而过，停留 8 秒）
2. 卡片状态变成红色的「已停止（重启失败）」
3. 日志里留一条记录

这样不会出现"以为在跑、其实早挂了"的情况。卡片下次启动时会自动清掉红色提示。

> 「连续」是真的连续：只要某次运行**稳定超过 60 秒**才退出，计数就清零重新算。
> 所以一个每天崩一次的服务不会被永久放弃自动重启 —— 只有短时间内反复崩才会。

### 遇到问题的排查顺序

1. 看界面底部有没有提示条（toast）
2. 展开「日志」面板，看有没有红色/异常记录
3. 打开 `logs\crash.log`，搜最近的时间戳
4. 导出诊断包，便于对照

## 10. 常见问题

**Q：批处理卡在「请按任意键继续」不动？**

A：说明这条用的是「正常窗口」或「最小化到任务栏」形态，窗口里的 `pause` 正在等按键，但窗口可能被挡住或最小化了。点任务栏把它调出来按任意键即可。想彻底避免这种情况，把窗口形态改成「后台运行」—— 启动器会自动跳过 `pause`。

**Q：批处理里的命令看不到输出？**

A：先看卡片的标记。显示「后台运行」说明输出在「日志」面板里，不在窗口；显示「最小化」说明窗口被最小化了，点任务栏恢复。

**Q：拷到别人电脑上，卡片全是灰的？**
A：说明那些条目的路径不在启动器目录内，记的是绝对路径。两个办法：① 把目标程序一起放进启动器目录再重新设置一次（会自动转成便携路径）；② 在对方电脑上重新点「设置」选一次。

**Q：双击没反应 / 打不开？**
A：先看任务栏和托盘是否已有实例（单实例会静默退出）。若被 SmartScreen 拦截，点「更多信息 → 仍要运行」；杀毒软件需加白名单。

**Q：设置改了但重启后又变回去？**
A：大概率是 exe 放在不可写目录（如 `C:\Program Files`），配置被改存到 `%LOCALAPPDATA%\大肥鱼启动器` 了。看「设置 → 关于」里的运行模式；想保持便携就把 exe 换个可写目录。

**Q：怎么把整个工具发给别人？**
A：见下一节。

**Q：日志面板没有输出？**
A：只捕获子进程的标准输出；GUI 程序（如 AstrBot 桌面版）通常不输出到控制台。

**Q：点 X 后程序去哪了？**
A：默认最小化到托盘（右下角），双击图标回来。

**Q：换电脑后开机自启失效？**
A：注册表里存的是旧 exe 路径。在新电脑的设置里重新勾选一次。

**Q：`%TEMP%` 里有一堆 `_MEI` 文件夹？**
A：那是单文件程序每次启动的解压目录。本版会在启动时自动清理**自己留下的**残留（带属主标记且进程已退出）。历史遗留的、没有标记的目录不会被自动删除（避免误删别的程序），可手动清理：关掉启动器后，在资源管理器地址栏输入 `%TEMP%`，删掉 `_MEI` 开头的文件夹即可。

## 11. 打包给别人的检查清单

1. 把 exe 放在一个**有写权限**的普通文件夹（不要放 Program Files）
2. 把目标程序放在 exe 同级或其子目录，路径会自动转成 `${APP}\...`
3. 确认卡片上没有「尚未设置路径」，也没有置灰的卡片
4. 关掉启动器，确认 `config.json` 里 `path` 字段是 `${APP}\...` 开头
5. 连同 `config.json`、`detect_rules.json`、`logs\`（可选）一起压缩
6. 在**另一台电脑或另一个路径**解压试跑一次，确认卡片路径有效

> 只拷 exe 不拷 `config.json`，对方打开就是三个空卡片，需要重新设置。

## 12. 开机动画

启动器可以播放一段开屏动画，**可以自己替换，不用重新打包**。

> 内置动画转码自 [Something11235/dsh-video-skin](https://github.com/Something11235/dsh-video-skin)（MIT）。
> 想换成自己的，直接按下面「怎么换」替换即可。

### 怎么换

把 `boot.webp` 或 `boot.gif` 放到**启动器 exe 同目录**，重启即可。

- 外部文件优先于内置的那份
- 删掉外部文件 → 回落到内置动画
- 「设置 → 启动时显示开机动画」可以整个关掉
- 开屏时点任意处即可跳过

### 支持的格式

动态 WebP（推荐，体积最小）、GIF、PNG 序列。

**不支持 MP4 / AVI** —— 那需要额外的视频解码组件（约 160 MB），不值得。用 ffmpeg 转一下就行：

```bat
ffmpeg -i boot.mp4 -t 6 -vf "setpts=PTS/3,fps=24,scale=900:-1" -c:v libwebp -loop 0 -q:v 50 -an boot.webp
```

### 时长建议

| 时长 | 体验 |
|---|---|
| 0.8 秒 | 几乎不拖慢启动 |
| 1.5–2.0 秒 | 观感完整，但启动会慢 1–1.5 秒 |
| 超过 3 秒 | 明显拖沓 |

### 为什么前面有一段黑屏

`--onefile` 打包每次启动都要把 36 MB 解压到临时目录，大约 1.1 秒。这期间 Qt 还没起来，**任何动画都显示不出来**。这是打包方式的固有限制，跟动画文件无关。

### 启动项动画

点卡片开关启动程序时，卡片会有一圈很淡的蓝色描边呼吸一次（760 毫秒），提示"正在启动"。不缩放、不闪烁。

## 13. 全屏判定的进程名单

设置里有两项可以调整"什么算全屏"：

| 设置项 | 作用 |
|---|---|
| **额外判定为全屏的进程** | 在内置名单（播放器、浏览器、`explorer` 等）之外，再把这些进程也算作全屏 |
| **不计入全屏的进程** | 优先级最高：即使它在内置名单或上面的名单里，也不会触发暂停 |

- 格式：逗号分隔（中文逗号也认），可省略 `.exe`，例如 `chrome.exe, myplayer`
- 改完点「保存」立即生效，不用重启
- 典型用法：某个游戏/播放器没被识别成全屏 → 把它加到第一个框；某个工具全屏但其实不该暂停服务 → 加到第二个框

## 14. 系统要求与限制

**要求**

- Windows 10 / 11，64 位（不支持 32 位、ARM64、Windows 7）
- 目标电脑无需安装 Python、PySide6 或 VC++ 运行库（已内置）
- 解压运行时需要 `%TEMP%` 可写（单文件程序会先解压到临时目录）

**已知限制**

- **未做代码签名**：首次运行会弹 SmartScreen 提示，杀毒软件可能误报，需手动放行
- **启动器只负责"启动"**：目标程序本身必须在对方电脑上存在且路径正确
- **`.lnk` 快捷方式无法跟踪/停止**：交给系统 Shell 启动，启动器只知道它被拉起过
- **`.bat` 会带控制台窗口**：选「最小化」只是最小化控制台，无法完全隐藏
- **全屏/进程避让依赖 Windows API**：仅在 Windows 下有效
- **单文件冷启动 1–3 秒**：PyInstaller 解压开销，属正常现象
